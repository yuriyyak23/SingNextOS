# Normative invariants

C1 Provider guarantee cannot authorize unauthorized SingNext work.  
C2 No irreversible execution unless provided guarantees semantically refine obligations.  
C3 `actual provider consumption <= bound execution envelope <= exact live SingNext lease`; measurement is evidence, not budget authority.  
C4 Resource envelope != effect authority.  
C5 For a contour capable of withholding output, staged publication requires an exact SingNext publication decision before adapter/provider publication action. Direct/coherent effects use contour-specific semantics and must not pretend a withheld gate exists.  
C6 execute != retire != complete != visible != published != released.  
C7 Relevant generation drift fails closed.  
C8 Measurement/completion/certificate/replay evidence != authority.  
C9 Replay evidence != permission to execute again; every new provider submission requires fresh authorization/admission/refinement/runtime legality.  
C10 A successful provider-contour containment closure proves no future new external effect only for the exact bound operation/provider generation and only if executable runtime enforcement exists. No generic global EffectEpoch claim.  
C11 Charging semantics are explicit per resource class; consumption is not defined as retired work.  
C12 Scheduler/planner cannot legalize a guarantee/obligation mismatch.

Additional: one logical fact has one authoritative owner, but an owner is not required to use one physical global lock. Unknown semantic versions/classes fail closed. No DTO/certificate/capability bit upgrades a claim beyond its executable evidence. ISA remains unchanged.
