# ADR-027 — Original native DMA visibility and exact grant closure

Accepted for actual additive ModelOnly producer/consumer, 2026-10-11; gates OFF, ISA NONE.

Actual kernel PreparePlatformDmaForDevice repro mutated a foreign realm equal numeric grant visibility cycle. Legacy native Prepare/Acquire and provider pre/post checks do not establish producing source continuity. Extend the optional original native DMA protocol with captured realm, original Bind invocation, grant and expected original cycle; retain intent/raw at the existing grant owner and check source/parent/cycle atomically with Prepare/Acquire under the lifecycle gate. Unknown reply never repeats visibility effect or authorizes a new cycle. Pure surviving-original visibility lookup validates the same source/factory and produced cycle/revision before provider publication; missing is unknown. Original owner history retains issued-count continuity so history loss or copies cannot initiate a second visibility effect.

An optional platform exact grant visibility-closure contract is resolved only for grants admitted through that actual original native producer. Native original Close serializes with synchronous visibility operations, revokes the same grant and removes visibility; later Prepare/Acquire refuse. This contains unfinished visibility invocation usage of that grant, including lost reply, but does not contain transfer/submission uncertainty, revoke physical DMA, or derive closure from object absence. Bridge retains visibility raw/pending fact separately from independent submission/source fault pins; only exact successful original grant Close consumes its owned visibility uncertainty. Generic/incapable paths stay conservative. Late callbacks/source loss cannot publish a cycle; cleanup uses original Close/retained outcome, never returned-object compensation.

No new authority/ledger, public enum/V2/schema/package or ISA changes. Existing local native project references adopt the additive protocol. Verify actual foreign realm unchanged, no-repeat/lost/malformed/raw-before-callback/reentry/owner/cycle continuity and exact kernel Region/attached charge reclaim; final native/affected/main exits bound the dev claim. General unknown/all-fact-loss/production/physical/stateful scopes remain separate.
