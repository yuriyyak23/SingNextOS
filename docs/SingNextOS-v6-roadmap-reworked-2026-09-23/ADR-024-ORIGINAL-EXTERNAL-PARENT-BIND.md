# ADR-024 — Captured native parent Bind source and surviving outcome

Accepted 2026-10-10. Actual first external parent Bind lost reply leaves an admitted
native parent, zero child Creates, failed kernel teardown and charge8192. ADR-023
cannot resolve a child invocation before its external parent admission is known.

Optional V1 preparation captures native producing source and the same original
Bind request before possible effect. It is an interlock/correlation, never
permission. The native owner checks its self-owned prepared request and source
atomically at invocation; foreign/equal-tuple copies cannot invoke Bind. Existing
provider admission owner retains intent, backend raw and external outcome before
diagnostic callbacks. Pure lookup returns only surviving same-original facts;
absence, unknown backend acceptance or history loss remain pinned/no-repeat.
Only exact producing pre-effect refusal can assert no-effect.

Adapter existing parent retains that prepared request and raw before callbacks.
Original child Create lookup first resolves the parent admission, then consumes
its exact never-invoked child component. It publishes no child/execution admission;
the surviving parent still requires existing original parent Close and actual
kernel Region/budget cleanup. Canonical owner/source loss needs fresh continuity;
completed facts survive late publication refusal without repeating Bind.

No new authority/ledger, enum/V2/wire schema or ISA/core architecture changes.
This is single-host surviving-fact dev scope; B1/general B2/all-fact-loss and
physical/multi-host remain open. Gates OFF. Actual package adoption and terminal
affected/main verification are required for bounded exit.
