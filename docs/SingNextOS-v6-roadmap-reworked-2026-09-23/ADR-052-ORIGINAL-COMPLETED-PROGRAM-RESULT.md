# ADR-052: Read the original Completed program result

Accepted for implementation, 2026-10-11. The actual compiled managed-array consumer completes with code42, while unhandled bounds failure completes the lifetime with code255. Existing public QueryVirtualDomain returns Completed for both and ObserveVirtualTrap correctly refuses a completed lifetime. A program-result reader needs the producer's retained exact result, without guessing success from Completed or rerunning execution.

Add an optional nullable ProcessExitCode to the existing terminal observations. The native owner captures it from its actual terminal runner result into the same original Start fact before return. Adapter/provider preserve it under existing original request/receipt/history/source validation. Legacy producers may omit it; absence is Unsupported/unknown for the new reader, never zero, success or closure. Existing terminal/failure interfaces and positional constructors remain additive.

RuntimeKernel ObserveVirtualExecutionResult uses current Read authorization on the exact domain Traps resource and current process/composed sources. VDA must have the same canonical original Completed publication and unchanged non-exhausted revision. The bridge reuses the existing original terminal pure-query protocol, including balanced lineage/guest interlocks, original admitted receipt/raw equality, retention before callbacks and fresh source/local final commit. Copied/malformed/changed/lost replies deny. Lost pure reply may retry against that same surviving original fact; no CPU effect is repeated. Late local ABA or source/history loss cannot be repaired by an equal tuple.

Reads do not change state, native pages, Region or quantitative charges. They do not authorize resume, acknowledge an event, infer no-further-use or release backing. Completed exact teardown stays independent; semantic-read failure must not repin already consumed closure. Native/adapter/provider/bridge/VDA remain their existing owners; there is no result ledger or recovery authority.

Actual package adoption requires Contracts1.34.1/Runtime1.23.11 and the kernel caller. Verification belongs to the [consumer record](../../artifacts/v6/iteration-20261011-original-completed-result/report.md). Gates OFF; ProductionQualified false; Java-only skipped; ISA NONE. General unknown/history loss, trusted durable cold continuation and whole-OS HybridCPU binary remain open.
