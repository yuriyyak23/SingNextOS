# ADR-023 — Original child Create surviving outcome cleanup

Accepted 2026-10-10. Actual native Create lost reply leaves one admitted child,
quarantined root, Region Owned/charge8192 and failed RuntimeKernel TerminateProcess.
ADR-011 exact invocation refusal remains; generic failure is not no-effect.

Optional additive V1 Create/request/lookup names the same original parent Bind
admission and Create request. Existing parent retains intent before effect;
canonical original parent/generation is fenced under its producing gate. Raw
known outcome/no-effect is retained before publication. Pure lookup requires the
same request/owner; missing history is pinned, not absence/closure inference.
Unknown original intent remains a dependent user and forbids parent closure.

Adapter/provider/bridge retain original request/raw, reserved identities and same
original parent lifetime before possible effect. Root teardown consumes surviving
outcome via cleanup-only child adoption and existing exact child Close, then
parent/process/Region/budget consumers. Independent quarantine/source mutations
are not consumed as this invocation's fault. No fresh execution permission is
published; interlocks balance, callbacks stay outside local commit locks.

First external parent Bind unknown remains independently pinned. No new authority,
ledger, enum/V2/schema, ISA/core architecture change. All-fact-loss/B1/general B2
remain open; gates OFF. Actual package adoption and terminal affected/main exits
are required for bounded closure.
