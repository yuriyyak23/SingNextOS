# ADR-053: original admitted image roots at native GC safepoints

Accepted for implementation, 2026-10-12. The actual compiler-produced leaf catch/rethrow→intermediate finally→ancestor catch consumer exposed premature reclaim: native EH retained the exception reference in the admitted image root, but the external execution provider did not connect that location to the collector. A subsequent managed call collected the exception object and rethrow exited255.

The existing GC owner binds the original admitted bootstrap static-root locations once, before any collection. The external execution owner retains backing before loader effects and binds only the successfully admitted image's exact locations to reads of that same memory. Location identities, pointer alignment/extent, overflow and deterministic root budgets are checked. The binding cannot be replaced or introduced after collection begins. No permission, execution, provider closure or persistence authority comes from a root descriptor or GC binding.

Each stopped guest collection reads current references from the original image backing before reachability/reclaim. Unreadable or malformed reads refuse collection; thrown reads propagate without reclaim and balance pending. Readers execute outside the binding gate. Single-context pending admission refuses overlap/reentry before a second collection effect. Existing explicit-root rejection of Static/StringLiteral impersonation remains unchanged: native image roots are consumed by the runtime collector owner, not relabelled as handles or helper temporaries.

Native EH may retain its root across calls and rethrow; existing leave-catch/runtime semantics clear it when appropriate. A zero root permits ordinary GC reachability rules to reclaim the heap object. GC reachability/reclamation is distinct from original executable backing, Region and quantitative budget retirement. Exact provider/artifact/guest/child/root closure remains required for backing release; history loss retains existing pins. No second lifetime ledger or root authority is introduced.

HybridCPU.ExternalRuntime1.23.12 carries the producer and managed-runtime implementation for immutable SingNextOS adoption. ExternalRuntime.Contracts1.34.1, operationSchema1.4.0 and ISA semantics remain unchanged. Model execution is not ProductionSecure/ProductionQualified; gates remain OFF.
