Added `MatrixMultiplyShapeV1`, optional right input and operation-specific validation. Arithmetic uses checked unsigned multiplication and rejects results beyond signed Region range. A, B and C must be distinct live handles; byte ranges must exactly equal MxK, KxN and MxN sizes. Provider capacity covers all three operands using checked addition.

Non-Matrix operations reject Matrix-only fields. Direct/coherent output remains gated; Matrix tests request `StagedRequired`. No descriptor authorizes execution.

One initial compile found test-fixture type mismatches and was corrected. The first full run then found one expected stale legacy P16 source hash. Only that exact tuple entry and its manifest hash were corrected; the closure lane passed 4/4 before the clean full rerun.
