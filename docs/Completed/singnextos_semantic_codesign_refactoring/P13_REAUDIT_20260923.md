## 4. Confirmed defect/remediation

- Critical: `ResourceBudgetRecoveryJournal.IsAllowedTransition` allowed `PossibleSubmit → CancelledPreSubmit`. An authenticated replay record could therefore misclassify post-possible-submit ambiguity as refundable pre-submit cancellation.
- Removed that transition. After possible submit only quarantine or exact/contained/conservative settlement is accepted. Added focused regression.
- The first full run correctly failed two historical hash-closure tests because the corrected source/test were pinned by P16 tuples. Exact tuple/trace/manifest hashes were updated; closure then passed 33/33 and the full core lane passed on rerun.
- No new reconciliation authority, ledger, automatic resubmit, refund or reclaim owner was introduced.
