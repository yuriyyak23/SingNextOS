## 4. Defect/remediation/regression

Confirmed semantic ambiguity: admission proof/result types did not explicitly expose their non-authoritative status. Added constant false properties `AuthorizesExecution`, `MaterializesCapability`, and `IsRuntimeAuthority`, plus a regression using an exactly admitted managed member. No runtime owner or transition was added.

An attempted equivalent annotation on `ManagedCapPolicyDescriptor` changed the exact toolchain-golden hash without adding enforcement value. It was reverted; the verifier source returned to SHA-256 `991a295e05e41f9dfaf1d2c0caedd24013321bfeae135f06dba0ea6c2f87da45`, and the golden lane passed. This is evidence that policy-source drift fails closed.
