## 4. Defect/remediation/regression

Confirmed gap: the previous test-only trace carried only a generic correlation and generation, so it could not distinguish external-operation or semantic-binding substitution. Added those exact identities for submit/completion/visibility/output/publication/settlement/release events, version/enum/canonical validation, and a fail-closed comparator. Non-external events reject unexpected external identities, preventing payload smuggling.

No live trace emission was added because doing so solely to satisfy a document would create an unevaluated hot-path dependency. The evidence DTO has no authorization or submit method and cannot mutate owners.

Ordinary SIP is the semantic oracle and remains the fallback. Barrier planner materializes owner-visible boundaries; provider execution stays rejected without a provider-neutral contract.
