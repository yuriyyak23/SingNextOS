## 4. Defects and remediation

- Provider execution class was not an explicit canonical member of `ExecutionGuaranteesV1`; two provider classes under an otherwise identical contract tuple could not be distinguished by the guarantee digest. It is now mandatory, canonical and digest-bound.
- Numeric, rounding, atomicity and partial-progress semantics had no typed provider-neutral refinement vocabulary. Added a pure dimension-specific evaluator; unknown versions/enums and unsupported mandatory dimensions fail closed.
- Added explicit regressions proving replay/trace reports expose no submit/authorization surface and cached evidence cannot survive live capability revocation.
- No descriptor, evaluator, trace, certificate or replay report gained authority; no owner or state machine was added.
