# Термины

| Термин | Значение |
|---|---|
| Authority | Единственный owner конкретного logical fact |
| Admission | Совместные OS/provider/refinement/current legality условия |
| Original | Exact factory-owned request/fact/raw, сохранённый до effect |
| Incarnation/generation/epoch | Freshness mutable lifetime, не просто numeric ID |
| Possible effect | После этой границы отсутствие reply не разрешает repeat |
| No-effect | Отсутствие effect конкретной попытки |
| Closure/no-further-use | Прекращение использования исходного ресурса |
| Publication | Commit видимости результата у publication owner |
| Consumption | Local commit exact fact соответствующим owner |
| Reclaim | Освобождение use/backing/charge после dependencies |
| Quarantine | Запрет нового use при retention unknown lifetime |
| Pin | Удержание dependency, не permission |
| ModelOnly | Свойство модели, без physical claim |
| RuntimeEnforced | Live enforcement named property/contour |
| ExecutableAdapter | Concrete executing adapter named contract |
| FutureGated | Выключенное до prerequisites направление |
| ProductionQualified | Закрытые obligations exact deployment |
| HCEXE | Compiler-produced guest executable artifact |
| SIP | Service/process клиентский contract слой кодовой базы |
| ISA NONE | Machine architecture изменения не входят в данный scope |
